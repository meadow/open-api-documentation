# Sending the customer to checkout

Mint a handoff token when the customer clicks checkout, immediately before you redirect them. Do not mint it when the cart is created, cache it or reuse it. Redirect the customer's browser to the returned `checkoutUrl`, which already includes the token, with a top-level navigation: a `303 See Other` redirect from your server or `window.location.assign()`. Because the token is in the URL, do not show `checkoutUrl` as a link the customer could copy or share.

The token expires 5 minutes after it is minted and can only be used once. That only limits the time between minting it and the customer reaching the checkout page: once there, the page exchanges it for a checkout session for that cart, so the customer has as long as they need to check out. Mint a new token each time the customer is sent to checkout.

If the token has expired or was already used, the customer sees "Checkout link expired" and is asked to return to your site and check out again. Their cart is unchanged, so mint a new token and redirect them again.

Any other query parameters you add to `checkoutUrl`, such as `utm_source`, are kept on the page.
