# Checking out

Carts are for [checkout handoff](/guides/checkout-handoff): you build the cart, and the dispensary's Meadow menu handles sign-in, pricing, payment and placing the order. To place the order yourself, use [Create an order](/endpoints/orders/create-order) instead.

When the customer checks out, redirect their browser to one of:

- **The cart's `checkoutUrl`**, which opens the menu's checkout on Meadow's domain.
- **The page of the dispensary's site that embeds the menu**, with `meadowPath=%2Fcheckout&meadowQuery=checkoutCart%3D{cartId}` added to its query string.

There the customer signs in, or checks out as a guest where the dispensary allows it, and places the order.

A cart can't be changed after it's created and can only be checked out once. To change the line items, create a new cart.

See the [Checkout Handoff guide](/guides/checkout-handoff) for the full flow.
